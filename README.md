# Rock Paper Scissors

A simple Rock Paper Scissors game built with JavaScript.

## How to Play

1. Open `index.html` in your browser
2. Enter `rock`, `paper`, or `scissors` when prompted
3. Game plays 5 rounds
4. Winner is announced at the end

## Features

- Case-insensitive input (ROCK, Rock, rock all work)
- Score tracking for both player and computer
- 5 round game with final winner announcement

## Technologies Used

- HTML
- JavaScript
